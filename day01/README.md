# Assignment 1: Personal Academic Website

In this project, I created a personal website hosted on GitHub Pages

## What I Did

- Signed up for GitHub and created a dedicated repository for the website.

- Used GitHub Flavored Markdown (GFM) to structure and write the content.

- Learned how to apply themes and designs generated by Jekyll on GitHub to customize the site's appearance.

## AI Prompt Used

The content and structure of the website were guided by the following prompt:

```
Create a simple, clean personal website for me, Sapir Green. I want it to feel like a personal academic business card, not a CV. Use a minimal design with subtle purple accents.

Include my background, research experience at Tel Aviv University and the Weizmann Institute, my current research in Dr. Tanita Wein’s lab, my research interests, and my goals for the Python course.

Use only the information I provide and keep the text concise and natural. Do not add or invent information.
```


## Overview of Website Sections

- Background & Identity: A brief introduction for Sapir Green, styled as a minimalist academic business card with subtle purple accents.

- Research Experience: Highlights past experience at Tel Aviv University and the Weizmann Institute, alongside current research in Dr. Tanita Wein’s lab.

- Interests & Goals: Outlines primary research interests and learning goals for the Python course.
